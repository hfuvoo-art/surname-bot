# Бот со списком людей и баллами (версия для Vercel)

Бот работает всегда, даже когда твой макбук выключен, и бесплатно.

Как он работает:

1. Человек заходит в бота и нажимает `/start`.
2. Бот просит имя, фамилию и нынешний балл.
3. Человек попадает в общий список.
4. Нажал на человека: ему +1,5 балла, и он уходит вниз списка.
5. Сверху те, у кого баллов меньше. Снизу те, у кого больше.
6. На кнопке видно: имя · баллы · дата и время последнего нажатия.
7. Когда кто-то нажимает, у всех остальных список тихо обновляется сам, без уведомлений.

## Что понадобится

- Токен бота от @BotFather (ты его уже получил).
- Аккаунт на [github.com](https://github.com). Там будет лежать код.
- Аккаунт на [vercel.com](https://vercel.com). Войди через GitHub.
- База данных Neon. Её создаём прямо из Vercel, отдельно регистрироваться не надо.

Тариф Vercel Hobby бесплатный, но только для личных некоммерческих проектов.
Neon на бесплатном тарифе не просит карту.

## Шаги

### 1. Положи код на GitHub

1. Распакуй архив `surname_bot_vercel.zip`.
2. На github.com нажми «+» вверху справа, потом **New repository**.
3. Назови его `surname-bot`. Видимость выбери **Public**. В коде нет токена и паролей,
   они будут храниться на Vercel, поэтому публичный репозиторий безопасен.
4. Нажми **Create repository**.
5. Нажми ссылку **uploading an existing file**.
6. Перетащи в окно файлы из распакованной папки: `app.py`, `handlers.py`, `storage.py`,
   `requirements.txt`, `set_webhook.py`, `README.md`. Саму папку не тащи, только файлы.
   Файл `.gitignore` скрытый, его можно не загружать.
7. Внизу нажми **Commit changes**.

### 2. Создай проект на Vercel

1. На vercel.com нажми **Sign Up** и **Continue with GitHub**. Выбери тариф **Hobby**.
2. Нажми **Add New** и **Project**.
3. Найди `surname-bot` и нажми **Import**.
4. Ничего не меняй и нажми **Deploy**.

Vercel сам поймёт, что это Python-приложение на FastAPI. Первый запуск пока ничего
не умеет, потому что не хватает настроек. Это нормально.

### 3. Подключи базу Neon

1. Открой свой проект на Vercel и зайди на вкладку **Storage**.
2. Нажми **Create Database** и выбери **Neon**.
3. Выбери бесплатный тариф и подключи базу к проекту `surname-bot`.

Vercel сам добавит переменную `DATABASE_URL` в проект. Руками её вводить не надо.

### 4. Добавь настройки бота

1. В проекте открой **Settings** и **Environment Variables**.
2. Добавь две переменные:

| Имя | Что писать |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `WEBHOOK_SECRET` | длинный случайный пароль, см. ниже |

Пароль для `WEBHOOK_SECRET` придумай командой в Терминале:

```
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

Скопируй результат, он понадобится ещё раз на шаге 6. Никому его не показывай.

3. Открой **Deployments**, у самого верхнего запуска нажми «три точки» и **Redeploy**.
   Новые настройки начинают работать только после нового запуска.

### 5. Проверь, что сайт жив

Открой в браузере адрес проекта (на Vercel он написан сверху, что-то вроде
`surname-bot-abc.vercel.app`). Должна появиться короткая строка с `"ok": true`.

### 6. Скажи Telegram, куда присылать сообщения

В Терминале на макбуке зайди в папку с файлами и выполни (подставь свои значения):

```
export BOT_TOKEN="токен_от_BotFather"
export WEBHOOK_SECRET="пароль_с_шага_4"
python3 set_webhook.py https://адрес-твоего-проекта.vercel.app
```

Скрипт сам проверит сайт, подключит бота и добавит меню команд. В конце должно быть:
`Ошибок нет. Напиши боту /start.`

### 7. Стань админом

1. Напиши своему боту в Telegram `/id`. Он ответит числом. Это твой Telegram ID.
2. На Vercel в **Environment Variables** добавь переменную `ADMIN_IDS` со своим числом.
   Если админов несколько, пиши через запятую: `11111111,22222222`.
3. Сделай **Redeploy** (как на шаге 4).
4. Напиши боту `/start`. Внизу появится кнопка «Админ-меню».

Всё готово. Отправь группе ссылку на бота.

## Если что-то не работает

- **Скрипт пишет ошибку 401 или 403.** Похоже, включена защита Vercel. Открой проект:
  **Settings**, **Deployment Protection**, выключи **Vercel Authentication**. Запусти скрипт ещё раз.
- **Бот молчит.** На Vercel открой вкладку **Logs** и посмотри ошибки. Запусти
  `python3 set_webhook.py https://...` ещё раз: в конце он покажет последнюю ошибку Telegram.
- **Первое сообщение после долгой паузы отвечает чуть дольше.** Бесплатная база Neon
  засыпает через 5 минут без работы и просыпается за пару секунд.
- **Поменял настройки, а ничего не изменилось.** Нужен **Redeploy**.

## Команды бота

Внизу экрана кнопки: «Регистрация», «Список», «Мой балл», «Помощь», у админа ещё «Админ-меню».
Рядом с полем ввода есть кнопка «Меню» со списком команд.

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | все | Регистрация или показ списка |
| `/list` | все | Показать список |
| `/me` | все | Мои баллы и место |
| `/help` | все | Помощь |
| `/id` | все | Узнать свой Telegram ID |
| `/remove Иван Иванов` | админ | Убрать человека из списка |
| `/reset` | админ | Обнулить баллы у всех |
| `/clear` | админ | Удалить весь список |

Админ-меню делает то же самое кнопками. Перед обнулением и удалением бот спрашивает подтверждение.

## Заметки

- Данные хранятся в базе Neon, а не в файле. Баллы из старой версии (`surnames.db`)
  сюда не переносятся, все регистрируются заново.
- Тихое обновление списка работает так: бот правит старые сообщения со списком.
  Telegram не уведомляет, когда сообщение меняется, поэтому у людей просто меняется порядок кнопок.
- Бот обновляет по три последних сообщения со списком в каждом чате.
- В списке не больше 99 человек (лимит Telegram на кнопки).
- Часовой пояс по умолчанию Москва. Поменять можно переменной `TZ_NAME`, например `Europe/Kyiv`.
- Чтобы человек зарегистрировался заново, админ убирает его через «Убрать человека».
- Чтобы отключить вебхук (например, вернуться к версии для ноутбука), запусти
  `python3 set_webhook.py --delete`.
